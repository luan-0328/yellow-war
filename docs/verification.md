# 第一版验证记录

日期：2026-10-31。环境：Windows、Node.js 24、Phaser 4.2.1。

## 自动化规则测试

`npm test`：10 项通过。

- 矿工真实往返后交付，每个周期只交付一次。
- 招募成功只扣一次金币；不足、暂停、基地死亡、人口满均不扣款。
- 暂停冻结经济、移动、AI、攻击与投射物。
- 死亡矿工停止交付；死亡战斗单位停止攻击；盾矛兵减伤 20%。
- 箭矢飞行期间不扣血，目标先死亡则移除投射物。
- 法师与巨人溅射仅伤敌方。
- 集合、防守改变战斗目标，矿工仍独立采矿。
- 双方经济满足 `400 + 矿工交付 - 招募支出 = 当前金币`，人口不超过 30。
- 不招兵会失败；结束后冻结；新模型恢复初始资源、单位和计时。
- 仅通过正常采矿、招募的策略在固定种子下 77.3 秒获胜；未修改基地血量或注入金币。

`npm run build`：严格 TypeScript 检查与 Vite 生产打包通过。

## 浏览器检查

- 主菜单六个正式 PNG 正确显示，原始素材文件保持不变。
- 开始游戏后双方各一名矿工；真实金币交付和快捷键招募生效。
- 战败结算已实际出现，可见时长、招募数和最终金币。
- 暂停遮罩、音量、静音、返回菜单可见。
- 844×390 横屏视口检查，主要战场按钮加高为 82 设计像素；保持 16:9。
- 修复 CSS flex 与 Phaser AutoCenter 重复居中的问题。
