# M0 视觉与工程决策

## 美术基线

用户给定六张黄色角色 PNG 是唯一角色设计源。保留原色、装备、比例和静态姿态；没有引入新角色、动画序列、emoji 或占位几何角色。

素材外围带 alpha，但腿间及少量边缘残留暖白色背景。`prepareCharacterTexture` 在首次加载时建立派生 CanvasTexture，通过背景连通的中性色与下部白色空隙清理 alpha；原 PNG 保持不变。主体黄色和上部装备高光受阈值保护。后续替换更干净的同角色素材时应撤掉这层素材专用处理。

## 视觉系统

- 青灰天空 `#66888D`，远山 `#718781`，草原 `#9B9B62`，沙土 `#C9AD79`，深褐面板 `#252B2C`，伙伴金 `#F0C457`。
- 英文标题 Georgia 粗体衬线；中文与功能文字使用系统 Microsoft YaHei / PingFang SC。无需外部字体请求。
- 主菜单左侧标题与操作，右侧完整六人队列；战场顶部导航、中部说明、下部主战线，控制条位于角色脚底下方。
- 场景、草地、堡垒和光照以 Canvas/Phaser 绘制并缓存背景纹理，不增加不相关的远程图片请求。
- 角色是最主要的饱和色；普通战场单位 160–175 px，巨人 240 px；菜单队列略放大以强调角色外观。
- 不做自动晃动/伪行走动画。按钮提供悬停与按下反馈，键盘按钮有可见焦点。

设计复核：通用检索推荐了网页 Feature-Rich Showcase、3D 与绿色配色。这与 Phaser 横版游戏不符，因此采用基于黄色伙伴、金属装备和旷野世界的自定义方向，保留通用对比度与交互可用性建议。

## 范围

M0 美术验收已保留。后续按用户继续开发的授权完成 M1–M6：堡垒接入独立基地生命值，双方拥有真实采矿经济、人口限制、招募、六兵种战斗和指令。M0 朝向检阅工具被正式战场取代；菜单仍完整展示六个角色。详细行为与当前边界见 README。
